Adding Books

Place EPUB files into the Book directory.

Browsing Books

  • UP/DOWN/SHOULDER: Select a book
  • A/RIGHT/START: Open the selected book
  • SELECT/Y: Enter and leave settings

Reading a Book

Tap on the left and right sides of the touchscreen to move through pages.

  • RIGHT: Next page
  • LEFT: Previous page
  • UP: Next bookmark
  • DOWN: Previous bookmark
  • A: Next page
  • B: Previous page
  • X: Invert colors
  • Y: Add a bookmark (hold to select a word)
  • SHOULDER: Next or previous page
  • SELECT: Add a bookmark
  • START: Return to the library

Adding Fonts

Add TrueType TTF files to the Font directory. You can then select them in the settings screen.

Adding Dictionaries

Place StarDict dictionary files (.ifo, .idx, and .dict or .dict.dz) into the Dictionary directory, either directly or inside a subfolder. If a dictionary uses .idx.gz, decompress it to .idx first. Optional .syn or .lem files are loaded automatically for inflected words.

You can then choose your active dictionary in the settings screen.

Looking Up Words

Tap and hold on a word on the touchscreen, drag to adjust the highlight, and release to show its definition on the opposite screen. Drag toward the hinge edge to select words on the opposite page, toward the outer edge to return, or to the bottom edge to cancel.

  • Y (hold): Select words with the D-pad (A to look up)
  • UP/DOWN: Scroll the definition
  • LEFT/RIGHT/SHOULDER: Browse nearby words
  • B: Close the definition
